# دومينو 3D Premium (Flutter / Dart)

لعبة دومينو ثلاثية الأبعاد: طاولة بمنظور 3D، أحجار مجسّمة بظلال وسُمك ولمعة، جاذبية حقيقية (سقوط + ارتداد + اهتزاز الكاميرا + موجة غبار)، أصوات مولَّدة، إعدادات كاملة، ولعب أونلاين بسيرفر Dart.

## بناء الـ APK على GitHub
1. ارفع **محتويات** هذا المجلد إلى مستودع GitHub (يجب أن يظهر `pubspec.yaml` و`.github` في جذر المستودع).
2. من تبويب Actions شغّل **Build APK** (أو يشتغل تلقائيًا عند الرفع).
3. حمّل `domino3d-apk` من Artifacts.

## الأونلاين
السيرفر في مجلد `server/` بلغة Dart فقط (بدون مكتبات):
```
cd server
dart run bin/server.dart        # المنفذ 8080 أو متغير PORT
```
- على جهازك/VPS: ضع في الإعدادات داخل اللعبة `ws://IP:8080`
- على Render / Fly.io / Railway: استخدم `Dockerfile` الموجود في الجذر (البناء من الجذر)، ثم ضع `wss://اسم-الخدمة.onrender.com`
- المحاكي: `ws://10.0.2.2:8080`

الأوضاع: **مباراة سريعة** (يُضاف بوت تلقائيًا بعد 12 ثانية إن لم يوجد لاعب)، **غرفة خاصة** بكود من 4 أرقام، **انضمام بكود**. إذا خرج لاعب أثناء اللعب يحلّ مكانه بوت.
